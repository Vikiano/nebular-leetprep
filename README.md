# LeetPrep Studio

The interview prep platform for candidates who value career integrity.

## Stack
- Next.js 15 App Router
- Supabase (Postgres + Auth)
- Anthropic Claude 4.7
- Tailwind CSS
- Deployed on Vercel

## Develop

```
npm install
cp .env.example .env.local
# fill in keys
npm run dev
```
